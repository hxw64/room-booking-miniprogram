# 独立作业提交说明

> **课程**：Project-Based Vibe Coding（Introductory Module）
> **对应评分项**：Independent assignment（5%）——用同一套 Vibe Coding 方法，做一个**非个人主页**的网站或小程序，提交一个可访问的版本和一段简短的迭代说明。
> **本项目**：房间 / 座位预约微信小程序

## 1. 一句话介绍

一个管理共享房间与座位预约的微信小程序：用户登录后可按半小时粒度预约房间或自习室座位，其他人可实时查看占用状态；管理员可编辑房间资料、审核长时段申请并查看预约人联系方式。

## 2. 面向谁、解决什么问题

- **使用场景**：8 个共享房间（801–808）+ 1 个公共自习室（803）的日常预约。
- **原来的麻烦**：口头 / 纸质登记容易撞时间，看不到哪里被占了，长时段借用也没人把关。
- **本项目的做法**：把"看占用 → 选时间 → 提交预约 / 申请 → 审核 → 报到"做成一条自助流程。

## 3. 用户与主要功能

| 角色 | 能做什么 |
| --- | --- |
| 访客 / 普通用户 | 浏览房间与座位占用、按半小时粒度预约、查看 / 取消自己的预约、报到 |
| 管理员 | 以上全部 + 编辑房间图片与介绍、查看全部预约、审核 / 驳回长时段申请 |

## 4. 可访问版本

本项目是微信小程序，可访问方式（按优先级）：

1. **微信体验版 / 正式版**：在微信开发者工具中上传代码，设为体验版后生成体验二维码，扫码即可访问（需要真实小程序 AppID 且已开通云开发）。
2. **H5 预览**：项目支持 `npm run build:h5`，可把 H5 产物部署到 GitHub Pages 等静态托管作为演示（登录 / 云函数等依赖微信环境的部分在 H5 中不可用，仅作界面演示）。
3. **源码 + 截图**：本仓库源码公开，配合 `docs/evidence/` 下的截图说明界面与流程。

## 6. 技术栈与目录结构

- 前端：uni-app（Vue3 + Vite），产出微信小程序
- 后端：微信云开发（云数据库 / 云存储 / 云函数）
- 目录结构与本地构建步骤：见仓库根目录 `README.md`

## 7. 隐私与合规自查

- **不含任何密钥**：仓库中没有 AppSecret / API Key；`src/config/index.js` 里的 `CLOUD_ENV` 是云环境 ID（部署标识，不是密钥）。
- **个人信息与公开数据分离**：预约人姓名、手机号、申请原因只存放在私有集合 `booking_details`（仅云函数可读，V3 迭代完成）。对前端开放的 `bookings` 只保留房间、座位、时间段与状态，**从公开数据里读不到任何预约人身份**。
- **管理端仍可见联系方式**：管理端列表由 `admin` 云函数关联 `booking_details` 后返回，姓名 / 手机号 / 申请原因照常显示。
- **写库集中在云函数**：前端只读占用信息 + 调用云函数，所有新增 / 修改（预约、取消、审核、房间编辑）都在 `cloudfunctions/` 中完成并做权限校验，前端不直接写库。
- **AI 使用**：借助 Codex（AI 编程助手）完成开发与文档；所有代码经本地测试与构建验证，规则与文案由作者本人核对确认。
