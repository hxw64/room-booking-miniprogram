# 过程证据（Evidence）

课程要求保留能说明过程的代表证据。请把下面这些放进这个目录，文件名建议带版本号，方便对照 `docs/迭代记录.md`。

## 需要放的证据

| 类型 | 建议文件名 | 说明 |
| --- | --- | --- |
| 改动前截图 | `v2-before-room.png` | 展示问题（如返回后占用状态未刷新） |
| 改动后截图 | `v2-after-room.png` | 展示修复结果 |
| 关键对话摘录 | `v2-prompt.md` | 当时给 AI 的关键提示词与关键回复（不必是完整聊天记录） |
| 反馈记录 | `feedback-v3.md` | 每位体验者的反馈原文 + 截图，至少 3 人、3–5 条 |

## 小提示

- 不必提交完整聊天记录，挑能说明"为什么这么改"的关键片段即可。
- 截图注意遮挡手机号等个人信息。
- 每加一份证据，回到 `docs/迭代记录.md` 对应版本补一行说明。
